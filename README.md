# CS131 Project - Data Alchemists

Team: Akshay K, Yogi C, Tomo S, Phu H.

A reproducible Unix workflow for inspecting, cleaning, validating,
and analyzing the instructor-altered historical stock-prices dataset.

The primary implementation will use Bash, awk, and standard Unix tools.
Raw input is preserved locally under data/ and excluded from Git.

Status: Project setup; implementation and verification in progress.
